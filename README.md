## Features

- **Syntax Guide**: Minimal skeleton, object model, Euclidean constructions, functions, loci, transforms, widgets, and troubleshooting.
- **Schema Reference**: Complete catalog of object kinds and registered constraints.
- **Interactive Sandbox**: Edit JSON and drag rendered sketches live in the browser.
- **Agent Skills**: Ready-to-use skill bundle for AI coding assistants to generate Web Sketch JSON or standalone HTML files.
